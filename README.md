# Smart Environmental Monitoring System (EcoSense Monitor)

A mobile-friendly Python + Streamlit dashboard prototype for environmental monitoring.

## Features
- Temperature, humidity, and air-quality cards
- Sample environmental trend charts
- Basic sample alerts and recommendations
- Responsive Streamlit layout

## Important
This project currently uses **sample/demo data**. It does not connect to real sensors and must not be presented as live measurements.

## Run locally
```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

## Deploy
Upload `app.py` and `requirements.txt` to a GitHub repository, then deploy the repository using Streamlit Community Cloud.
